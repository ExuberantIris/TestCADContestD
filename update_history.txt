weighted shuffle: greedy branch 打亂方法加入權重設計:
一個 branch 牽涉到的「目前違規 path」越多，權重越高（base 1.0，每牽涉一條違規 path +2.0。
然後用這個權重做「加權隨機排列」Efraimidis-Spirakis 方法：
每個 branch 抽一個 u~Uniform(0,1)，算 key = u^(1/權重)，
照 key 由大到小排序——權重越高，key 越容易接近 1，越容易被排到前面。
如果所有權重都一樣，這個方法會退化成跟均勻隨機洗牌完全等價。
(不過第一個 iteration 依然是起始拓樸排序)
